# The contract

Reference only — Lovable does not need to write these files. They show what
the finished template becomes on our side, so the values asked for at the
end of the prompt are the ones that actually get used.

- **theme-type.ts** — the shape a template takes in our engine.
- **theme-example.ts** — a real template (Dubai Silk) filled in.

Note how little it holds: a palette, two fonts, four asset paths, some
timings. That is the whole template. Everything else — the envelope and door
animations, the gesture-primed audio fade, the scratch canvas, the
countdown, the milestone counters — already exists and is shared by every
template.

So the only things that need creating are:

1. **The four images.** This is the real work.
2. **The fourteen palette colours.**
3. **Two Google Font names.**
